# git-work

这个仓库由 DeepSeek Harness 初始化。

## 开始使用

```bash
# 查看状态
git status

# 添加并提交
git add .
git commit -m "描述你的改动"
```

## 说明

- 该文件夹初始化时为空，此 README 与 `.gitignore` 为占位起始文件，可随时替换或删除。
- 提交身份已按本机账户临时设置，推送前请改为你自己的 GitHub 邮箱：

```bash
git config user.name  "你的名字"
git config user.email "你的邮箱"
git commit --amend --reset-author --no-edit
```
